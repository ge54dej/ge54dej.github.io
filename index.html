01 Bachelor Thesis

Lab Automation with SiLA 2

Making laboratory devices intelligent and automation-compatible — TU Munich · MIRMI · Robotics & System Intelligence Chair · Supervised by Prof. Dr.-Ing. Sami Haddadin · Advisor: Moritz Eckhoff.

Demo — Full end-to-end automated experiment run
Motivation

Lab workflows require manual handling and one-off per-device integrations. This slows experiments, introduces human error, and makes scaling to 24/7 operation impossible.

Approach

Implemented a SiLA 2 Server–Client architecture so the Franka Panda robot and a Thermo Fisher Varioskan LUX plate reader could be orchestrated from a single Python script — no GUI needed.

Result

Delivered a complete, repeatable end-to-end run: robot loads plate → device runs experiment → robot unloads. Modular architecture lets new devices be added without rewriting the system.

Tools & Stack
Franka Panda SiLA 2 Python C++ C# libfranka Varioskan LUX

02 Projects

Hands-on projects from coursework combining motion planning, robot control, and software integration.

Project 01 — RoboDK · UR10e
DrawBot — SVG Drawing on a Whiteboard

Built a pipeline in RoboDK that converts SVG vector files into robot drawing trajectories, rendering shapes on a whiteboard using a UR10e arm.

Key Points
  • Sampled SVG Bézier curves into discrete waypoints at fixed resolution.
  • Handled coordinate transforms across different SVG viewBox values.
  • Tuned joint speed near sharp corners to prevent overshoot.
  • Validated on three shapes testing different drawing challenges.
Tools
RoboDK UR10e SVG Python
Project 02 — Franka Panda · ROS 2
PolishBot — Automated Whiteboard Erasing

Implemented a reliable erase routine on the Franka Panda using ROS 2. The wipe trajectory was recorded by physically guiding the robot by hand, joint positions were captured at each timestep and saved. That recorded path is then replayed consistently, while the Franka's impedance control maintains steady contact force against the board without needing a force sensor.

Key Points
  • Hand-guided robot teaching to record the wipe trajectory.
  • Franka FCI used for real-time control; ROS 2 for monitoring.
  • Z-axis impedance tuned for stable contact without force sensing.
  • Implemented in Python and C++.
Tools
Franka Panda ROS 2 Python C++ libfranka
